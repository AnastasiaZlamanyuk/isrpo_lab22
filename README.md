# Lab22_JS_Interactive - Калькулятор
## 1. Описание проекта
Интерактивный веб-калькулятор, разработанный в рамках лабораторной работы №22. Проект демонстрирует использование современных технологий веб-разработки: HTML5, CSS3 и JavaScript (ES6+). Калькулятор реализован с применением объектно-ориентированного подхода и модульной архитектуры.

**Основные характеристики:**
- Чистый и интуитивно понятный интерфейс
- Безопасная обработка математических выражений
- Валидация пользовательского ввода
- Адаптивный дизайн
- Модульная архитектура с использованием ES6 модулей
## 2. Функциональность

### Поддерживаемые операции
- **Арифметические операции:** сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`)
- **Десятичные дроби:** поддержка чисел с плавающей точкой (`.`)
- **Очистка:** кнопка `C` для полного сброса
- **Вычисление:** кнопка `=` для выполнения операций

### Ограничения
- Деление на ноль обрабатывается как ошибка
- Запрещены множественные операторы подряд (например, `5++3`)
- Точка может быть использована только один раз в числе (например, `5.2.1` - запрещено)
- Выражение не может начинаться или заканчиваться оператором
- Максимальная длина выражения ограничена только возможностями JavaScript

### Обработка ошибок
Калькулятор безопасно обрабатывает следующие ситуации:
- **Деление на ноль:** отображается сообщение "Ошибка"
- **Некорректные выражения:** например, `5++3` → "Ошибка"
- **Синтаксические ошибки:** недопустимые последовательности символов
- **Ошибки eval:** все исключения перехватываются и выводятся пользователю

При возникновении ошибки:
1. На дисплее отображается "Ошибка"
2. Внутреннее состояние сбрасывается
3. При нажатии любой кнопки калькулятор очищается и готов к новым вычислениям

### Описание класса Calculator
Класс Calculator представляет собой отдельный модуль, который инкапсулирует всю логику работы калькулятора. Внутри класса есть несколько ключевых полей: displayElement хранит ссылку на поле ввода в DOM, expression хранит текущее математическое выражение в виде строки, а hasError представляет собой флаг, указывающий, находится ли калькулятор в состоянии ошибки.

Конструктор класса принимает идентификатор элемента дисплея и сохраняет ссылку на этот DOM-элемент, а также инициализирует пустую строку выражения и сбрасывает флаг ошибки в false.

Метод init отвечает за инициализацию калькулятора. Он собирает все кнопки калькулятора и для каждой навешивает обработчик события click, который будет вызывать метод handleButtonClick с текстом нажатой кнопки.

Метод handleButtonClick является главным обработчиком нажатий. Он определяет тип нажатой кнопки и вызывает соответствующие методы: clear для очистки, calculate для вычисления, либо добавляет символ в выражение с предварительной валидацией.

Метод clear сбрасывает выражение в пустую строку, убирает флаг ошибки и обновляет дисплей. Метод updateDisplay отвечает за отображение текущего выражения на экране, при этом если выражение пустое, показывает ноль.

Метод calculate выполняет вычисление накопленного выражения, предварительно проверяя, что выражение не пустое и последний символ не является оператором. Затем он вызывает safeEvaluate для безопасного вычисления.

Метод safeEvaluate является оберткой над eval. Он проверяет корректность выражения через isValidExpression и в безопасном блоке try-catch выполняет вычисление, при ошибке вызывая showError.

Метод isValidExpression проверяет выражение на наличие двойных операторов подряд, что предотвращает ввод некорректных конструкций вроде "5++3".

Метод isOperator определяет, является ли переданный символ математическим оператором. Метод isLastCharOperator проверяет, заканчивается ли текущее выражение на оператор.

Метод hasDuplicateDot проверяет, есть ли уже точка в последнем введенном числе, что предотвращает ввод чисел с несколькими десятичными точками.

Метод showError устанавливает флаг ошибки, выводит сообщение "Ошибка" на дисплей и сбрасывает выражение.

### Схема взаимодействия компонентов
Взаимодействие компонентов строится по принципу модульной архитектуры. Файл index.html содержит HTML-разметку калькулятора с контейнером div, полем ввода с идентификатором display и набором кнопок, созданных явно без использования циклов.

Файл style.css подключается к HTML и содержит все стили: центрирование калькулятора на странице, оформление темного фона, настройку сетки кнопок через CSS Grid, стилизацию поля ввода и специальное оформление кнопки равно, которая растягивается на всю ширину.

Файл main.js является точкой входа. Он импортирует класс Calculator из модуля calculator.js, создает экземпляр класса, передавая идентификатор элемента дисплея, и вызывает метод init для запуска калькулятора.

Файл calculator.js содержит определение класса Calculator со всей бизнес-логикой. Этот модуль экспортирует класс для использования в других файлах. Все внутренние переменные и методы класса изолированы и не попадают в глобальную область видимости благодаря использованию ES6 модулей.

Взаимодействие происходит следующим образом: при загрузке страницы браузер загружает main.js как модуль, который создает объект Calculator. Этот объект получает ссылку на DOM-элементы, навешивает обработчики событий на кнопки. При клике пользователя срабатывает обработчик, который вызывает метод handleButtonClick, а тот в свою очередь обращается к другим методам класса для валидации, вычисления и обновления отображения.

## 4. Логика работы

### Последовательность действий при нажатии кнопок
При нажатии на любую кнопку первым делом срабатывает обработчик события click, который вызывает метод handleButtonClick с текстом нажатой кнопки.

Внутри метода сначала проверяется состояние ошибки. Если калькулятор находится в состоянии ошибки и нажата любая кнопка кроме очистки, автоматически вызывается метод clear для сброса ошибки.

Затем определяется тип нажатой кнопки. Если это кнопка C, вызывается метод clear, который сбрасывает выражение и обновляет дисплей.

Если нажата кнопка равно, вызывается метод calculate. Внутри calculate сначала проверяется, что выражение не пустое и последний символ не является оператором. Затем вызывается safeEvaluate, который вычисляет выражение. При успешном вычислении результат сохраняется в expression и выводится на дисплей. При ошибке вызывается showError.

Если нажата кнопка с оператором, выполняется проверка: если выражение пустое, оператор не добавляется; если последний символ уже является оператором, текущий оператор заменяет предыдущий; в противном случае оператор добавляется к выражению.

Если нажата кнопка с цифрой или точкой, сначала проверяется, что при вводе точки в текущем числе нет уже точки. Если проверка пройдена, символ добавляется к выражению.

После любого успешного добавления символа вызывается updateDisplay для обновления экрана.
### Как работает валидация ввода
Валидация ввода реализована через несколько проверочных методов, которые срабатывают до добавления нового символа в выражение.

Проверка на двойные операторы осуществляется через метод isValidExpression. Он проверяет, чтобы в выражении не встречалось двух операторов подряд, например, "5++3" или "5*/2". Если такая ситуация возникает, символ не добавляется.

Проверка оператора в конце выражения выполняется методом isLastCharOperator. При попытке ввести оператор проверяется, не является ли последний символ в выражении уже оператором. Если является, новый оператор заменяет предыдущий, что предотвращает накопление операторов.

Проверка на повторную точку реализована в методе hasDuplicateDot. Этот метод извлекает последнее число из выражения, разделяя строку по операторам, и проверяет, содержит ли оно уже десятичную точку. Если точка уже есть, ввод дополнительной точки блокируется. Это позволяет вводить десятичные дроби, но предотвращает некорректные числа вроде "5.2.3".

Дополнительная валидация происходит при нажатии кнопки равно: проверяется, что последний символ выражения не является оператором, так как выражение, заканчивающееся на оператор, не может быть корректно вычислено.

При возникновении любой ошибки вычисления вызывается метод showError, который переводит калькулятор в состояние ошибки, выводит сообщение "Ошибка" на дисплей и сбрасывает выражение. Из состояния ошибки калькулятор выходит при нажатии любой кнопки, что позволяет пользователю начать новый расчет.

### Как происходит вычисление
Процесс вычисления начинается при нажатии кнопки равно, которая вызывает метод calculate. На первом этапе calculate проверяет, что выражение не является пустой строкой и последний символ не является математическим оператором, так как выражение вроде "5+" не может быть корректно вычислено.

Затем вызывается метод safeEvaluate, который принимает строку выражения. Внутри safeEvaluate сначала выполняется дополнительная проверка через isValidExpression, которая убеждается в отсутствии двойных операторов и общей корректности формата.

Если проверка пройдена, выражение передается в функцию eval внутри конструкции try-catch. Eval выполняет строку как JavaScript-код, вычисляя математическое выражение. Например, строка "5+3" преобразуется в число 8, а "10/2" в число 5.

При успешном вычислении результат, который является числом, преобразуется в строку и сохраняется в переменную expression. Это позволяет пользователю продолжить вычисления, используя полученный результат как основу для новых операций. Затем вызывается updateDisplay для отображения результата на экране.

Если в процессе вычисления возникает ошибка, например, при делении на ноль или при синтаксически некорректном выражении, блок catch перехватывает исключение и вызывает метод showError. Этот метод выводит на дисплей сообщение "Ошибка", устанавливает флаг hasError в true и сбрасывает выражение в пустую строку.

Важно отметить, что после успешного вычисления результат остается в expression, что позволяет пользователю, например, нажать оператор и продолжить вычисление с полученным числом. Если пользователь нажмет равно повторно, выражение будет вычислено снова, что может привести к повторному применению оператора к результату.
